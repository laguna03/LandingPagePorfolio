# Pedro Laguna — Landing Page Portfolio

A professional, animated portfolio site to showcase landing page services and projects.

## 📁 File Structure

```
index.html   → Main page structure & content
styles.css   → All styling (dark theme, animations, responsive)
script.js    → Interactions (tabs, counters, scroll reveal, form)
```

## ✏️ How to Update the 6 Portfolio Cards

Each card has comment blocks like `<!-- UPDATE ... -->` to guide you:

### Real Business Projects (cards 1–3)

1. Change `<h3 class="card-title">` — your project name
2. Change `<p class="card-desc">` — a short result/description
3. Change `href="#"` on the `overlay-cta` link — the live URL
4. Change `--cg: linear-gradient(...)` on `.card-preview` — card background color

### Example Designs (cards 4–6)

Same steps as above.

## 🔗 Other Things to Update

- **Email**: Search for `hello@pedrolaguna.com` and replace with yours
- **Social links**: Find `.social-btn` anchors in the footer
- **Pricing**: Edit the `$` amounts in the Pricing section
- **Testimonials**: Update quotes and names to match real clients
- **Contact form**: Wire up to Formspree, EmailJS, or your backend in `script.js`

## 🚀 To Preview

Open `index.html` in any browser — no build step needed.
